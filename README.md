# 🛒 Sales Forecasting for Retail Business

**Task 1 - Time Series Forecasting Project**

This project builds a forecasting model to predict future sales trends using retail sales data. It leverages time series techniques and regression to analyze patterns, trends, and seasonality in sales.

## 📌 Tools Used
- Python  
- Prophet  
- Scikit-learn  
- Pandas  
- Matplotlib

## 📊 Key Skills
- Time Series Forecasting  
- Regression Analysis  
- Trend & Seasonality Detection

## 📁 Dataset
Daily/weekly/monthly sales data including:
- `ORDERDATE`, `SALES`, `QUANTITYORDERED`, `PRICEEACH`, `PRODUCTLINE`, `DEALSIZE`, etc.

## ✅ Deliverables
- Accurate sales forecasting model  
- Visualizations of forecast accuracy and seasonality  
- Robust evaluation with time series cross-validation
